# VinceNoir — notes for Claude

The owner writes in Turkish; answer in Turkish. Code, comments and in-game text stay in English.

## What this is
Unity **6000.6.3f1**, Built-in Render Pipeline, legacy Input Manager, Humanoid avatars, Windows / DX11 build.
A noir third/first-person shooter: detective Vince "Slim" Walker in "Valentino's", a 90's mafia bar-restaurant with 18 bots.
The player character is generated in Blender by Python (`Blender/`); everything in Unity is **generated by editor scripts**.

## The golden rule: scenes and assets are generated
`VinceNoir > 1. Setup Everything` (`VinceSetup.SetupAll`) rebuilds: model import settings + humanoid avatar, Mixamo slot
fixes, `Vince.controller`, `Bot.controller`, all materials, procedural textures/meshes, both scenes (`NoirTest`, `BarValentino`),
light probes, reflection probes, the lightmap bake, occlusion culling, build settings. Hand edits to scenes are overwritten.
Change the editor code instead:
- `Editor/VinceSetup.cs` — menu, model import (`MatTable`, `CharacterMaterial`), Vince's animator, `CreatePlayer`, alley scene, `SetupLODs`.
- `Editor/VinceBarSetup.cs` — bot animator, `Populate` (director, flee points, patrol, bot specs, Vince's spawn), `MakeBot` (looks), `BuildRagdoll` (hitboxes).
- `Editor/VinceBarScene.cs` — the bar: layout, props, lights (Baked / Mixed / Realtime), shafts, neon, probes, `Bake()`.
- `Editor/VinceArt.cs` — procedural textures (`Make`, bump `Version` to regenerate) and the mesh toolkit (RoundedBox, Lathe, Tube, Extrude, Curtain, Tablecloth). Front faces: `Cross(b-a, c-a)` points out.
- `Editor/VinceProps.cs` — prop meshes (chair, piano, chandelier, sedan, fedora...).
- `Editor/VinceSetupCheck.cs` — "setup is outdated" dialog; bump `SetupVersion` when the generated content changes.

## Runtime
- `VincePlayer` (exec order 100): movement, gun states (`Holstered, Drawing, Drawn, Holstering, StealthDrawing, Concealed, StealthHolstering`),
  C once = stealth draw, C twice = normal draw, RMB from Concealed = quick draw; aim IK in LateUpdate; jacket flap bones (JkF_/JkB_);
  timings in `CarryFrames` / `StealthFrames` must match the Blender clips. Death = ragdoll.
- `PlayerHealth` — wound model (Zone: Head, Neck, Heart, Lung, Belly, ArmL/R, LegL/R), bleeding, tourniquet (H), drives `NoirPostFX` wound layer.
- `MafiaBot` (exec order 120) — suspicion → alarm, cover AI, physical bullets (`AimError`), suppression, magazines, wound rules incl. vest.
- `BarDirector` (exec order -50) — runtime navmesh bake, cover points from colliders named `Cover_*`, alarms, shot tokens (`MaxShooters`), doorman, decals, `-autotest` / `-perftest` / `-alleytest`.
- `BarAmbience` + `JazzSynth` — procedural audio on a worker thread (rain, piano, clinks, car), haze, rain particles, car-light sweep.

## Layers and masks
- 2 = Ignore Raycast: Vince's CharacterController and all his renderers, casings, decals.
- 8 = bot hitboxes (ragdoll colliders). 9 = Vince's hitboxes (`VincePlayer.HitLayer`); `Physics.IgnoreLayerCollision(2, 9)`.
- Vince's rays use `VincePlayer.WorldMask` (~2 & ~9). Sight lines use `SightMask` (~2, ~8, ~9). Bot bullets use `FireMask` (~2).

## Character pipeline
`Blender/build.py` → `Vince_Slim_Walker.blend`; `Blender/anim.py` (run on that .blend) → animated .blend + FBX.
anim.py merges parts into `Body`, `HeadGroup`, `Tie`, `Sunglasses`, pistols... and makes `Body_LOD1/2`, `HeadGroup_LOD1/2`;
UV2 "FabricUV" = metres along torso / legs / sleeves for the cloth patterns. Renderer names are used by code (see `VincePlayer.Awake`,
`MafiaBot.Awake`, `MakeBot` strip list, `HeadPartNames`). `Tools/BlenderExport.ps1` runs it (Blender's Python dislikes long paths).

## Build / test loop (editor closed)
`Tools/BuildAndTest.ps1 [-Step setup|build|none] [-Test autotest|perftest|alleytest]` → `TestRuns/`.
Autotest logs `[BARTEST]` / `[AUTOTEST]` lines and screenshots; perftest logs `[PERF]` per phase. Robocopy exit codes 1/3 = success.

## Bar layout (world, metres)
Facade z=0 (door x ±1.3), street z<0 (road y=-0.12, player spawn (0,-0.12,-11)), hall x ±19, z 0.2..28, ceiling 5.0.
Bar counter x≈11.9 z 8..22, back bar x≈18.7; tables `VinceBarScene.TablePos`; booths x≈-17 z 8/12.5/17/21.5 (windows above);
pillars (-4.5|5.6, 12.5|17.5); stage x -15..-5 z 23..28 (piano at `PianoBench`, yaw 35); VIP x 5.5..14.5 z 23.6..28;
kitchen x 8.8..19 z 28..34 (flee); restroom corridor x -19..-11 z 28..32 (flee).

## Performance budget (perftest on the dev machine)
~150 fps street, ~250 fps in the hall, ~270 fps in a firefight, no frame over ~20 ms. Keep it: no realtime shadows in the bar
(`QualitySettings.shadows` off in BarDirector), people are probe-lit + blob shadows, statics are batched and lightmapped,
no allocations per frame (NonAlloc raycasts, cached GUI styles, `useGUILayout = false`).
