Drop humanoid animation FBX files here (for example from mixamo.com, 'FBX for Unity', 'Without Skin').
Name each file after the slot it replaces:

  Idle  Walk  Run  WalkBack  StrafeLeft  StrafeRight          (locomotion)
  JumpStart  Fall  Land                                      (jump: take-off, falling loop, landing)
  CrouchIdle  CrouchWalk                                     (crouch, Ctrl)
  PistolIdle  PistolWalk                                     (right arm while the pistol is drawn)

Then use the menu  VinceNoir > 3. Apply Custom Animations.
Delete a file and apply again to go back to the built-in animation.
Aim / Shoot / Reload stay the built-in pistol animations.
